# RDK 社区与生态

第一步是弄清楚去哪里找资料。开发中遇到问题时，下面四类资源各有用处。

## 四类常用资源

- **官方文档** 用来确认开发板接口、系统镜像版本、API 和官方支持的操作流程。
- **课程讲义** 从明确的起点出发，带你完成一项任务并得到可检查的结果。
- **课程示例** 提供与具体课程对应、可以直接运行的代码。
- **社区渠道** 用来搜索别人遇到过的问题。官方资料不足时，也可以提交完整的复现信息寻求帮助。

## 先确认产品分支

RDK X5、RDK S100 和其他产品在系统镜像、接口、串口参数与软件包方面可能不同。复制命令或连接外设之前，先确认当前文档对应的开发板。

!!! warning "不要混用不同产品的操作说明"
    另一款 RDK 产品的命令或引脚定义可能看起来很接近，但不一定适用于你的开发板。请以对应产品的官方手册和当前系统版本为准。

## 怎样提交有效的问题

请写明开发板型号、系统镜像版本、主机系统、完整操作步骤、预期结果和实际结果，并附上能够显示首次失败位置的最小完整日志。
