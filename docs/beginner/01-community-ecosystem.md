# Community and ecosystem

Start by learning where RDK developers find the information needed to move a project forward.

## The four resources

- **Official documentation** for board interfaces, image versions, APIs, and supported workflows.
- **Course tutorials** for a guided explanation with a defined starting point and expected result.
- **Course demos** for runnable code that belongs to a specific lesson.
- **Community channels** for searching prior issues and sharing a complete reproduction when the documentation is not enough.

## Choose the right board branch

RDK X5, RDK S100, and other product families can differ in images, interfaces, serial parameters, and software packages. Confirm the board branch before copying a command or wiring an interface.

!!! warning "Do not mix board instructions"
    A command or pin mapping from another RDK family may look familiar and still be wrong for your board. Treat the exact board manual and image release as authoritative.

## A useful issue report

Include the board model, image version, host system, exact steps, expected result, observed result, and the smallest complete log that shows the first failure.
