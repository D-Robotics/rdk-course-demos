# RDK 小课堂

RDK 小课堂面向使用 D-Robotics RDK 开发板的开发者。课程从系统启动和硬件接口讲起，逐步覆盖模型部署、机器人应用、系统开发与具身智能。

## 课程

### [01 · 基础入门](beginner/index.md)

先让开发板正常工作，再掌握日常开发中最常用的操作，包括烧录镜像、排查启动问题、远程连接、使用摄像头与音频设备，以及操作 GPIO、PWM、UART、I2C、SPI 和 CAN。涉及硬件连接与操作差异时，RDK X5 和 RDK S100 使用各自独立的讲义。

### [02 · ModelZoo 与 RoboGo](modelzoo/index.md)

在 RDK 上运行现成的 AI 模型，并把模型示例整理成可以复现的应用。

### [03 · TROS](tros/index.md)

使用 TROS 开发机器人应用，内容从功能包和传感器节点延伸到感知流程与启动调试。

### [04 · 系统与驱动](system-drivers/index.md)

了解应用层以下的 RDK 系统、BSP、外设驱动与板级调试方法。

### [05 · 大模型与具身智能](embodied-ai/index.md)

学习在 RDK 平台上开发大模型、多模态交互和具身智能应用。
