# RDK Classroom

RDK Classroom is a practical learning platform for developers building with D-Robotics RDK boards. The tutorials take you from first boot and hardware interfaces to model deployment, robotics applications, system development, and embodied AI.

## Courses

### [01 · Fundamentals](beginner/index.md)

Get an RDK board running and learn the workflows you will use every day: flashing an image, troubleshooting boot issues, connecting remotely, using cameras and audio, and working with GPIO, PWM, UART, I2C, SPI, and CAN. Board-specific lessons are provided separately for RDK X5 and RDK S100.

### [02 · ModelZoo & RoboGo](modelzoo/index.md)

Run ready-to-use AI models on RDK hardware and turn model demos into reproducible applications.

### [03 · TROS](tros/index.md)

Build robotics applications with TROS, from packages and sensor nodes to perception pipelines and launch-time debugging.

### [04 · System & drivers](system-drivers/index.md)

Go below the application layer to understand the RDK system, BSP, peripheral drivers, and board-level integration.

### [05 · LLMs & embodied AI](embodied-ai/index.md)

Explore large-model applications, multimodal interaction, and embodied intelligence on RDK platforms.
