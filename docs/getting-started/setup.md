# Set up your RDK

Before starting a tutorial, record the exact board model, hardware revision, system image, host operating system, and the interfaces you plan to use.

## Prepare the host

Install the tools required by the lesson. Keep board data cables separate from power-only cables, and use the power adapter specified by the board documentation.

```bash
git clone https://github.com/D-Robotics/rdk-course-demos.git
cd rdk-course-demos
```

## Keep versions visible

When reporting a problem, include the output of the board's version command, the image name, and the host-side tool version. A tutorial should never assume that two board families share the same image or serial settings.

## Before you ask for help

Capture the command you ran, the expected result, the observed result, and the complete error or boot log. Include a link to the exact tutorial and course-demo directory you followed.
