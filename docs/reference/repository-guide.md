# Repository guide

The repository stores code that is used by a course lesson. It is not a replacement for the official RDK manuals.

```text
rdk-course-demos/
├── 01_beginner/       # foundational board and peripheral lessons
├── 02_modelzoo/       # model deployment lessons
└── 03_tros/           # robotics application lessons
```

Use the matching course directory when following a tutorial. A directory may stay empty while a lesson is being prepared; the documentation site can still expose the planned learning path.
