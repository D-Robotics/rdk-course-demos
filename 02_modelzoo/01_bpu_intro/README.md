# Meet the BPU Sources

This directory stores the standalone bilingual HTML pages and slide specs for the Meet the BPU tutorial (RDK Classroom, Chapter 2 Model Zoo, Lesson 1).

- English handbook: [`docs/modelzoo/bpu-intro.md`](../../docs/modelzoo/bpu-intro.md)
- Chinese handbook: [`docs/modelzoo/bpu-intro.zh.md`](../../docs/modelzoo/bpu-intro.zh.md)
- English slide source: `lesson-2-01.html`
- Chinese slide source: `lesson-2-01.zh.html`
- English slide spec: `blueprint.json`
- Chinese slide spec: `blueprint.zh.json`

The HTML slides are self-contained; open them directly in a browser. Use ←/→ to change slides, N for speaker notes, F for full screen, and S for the scroll view.

The slide specs use the deck schema (`mode: deck`, layout-based slides with speaker notes), not the pattern-based blueprint schema used by earlier lessons.

The lesson covers RDK X5, RDK S100, RDK S100P, and RDK S600 on the RDK Model Zoo `main` branch. Toolchain versions are not fixed here; follow the sample READMEs and the toolchain documentation.
