# Lesson 09 — Display Module

This directory contains independently openable HTML slide decks and their source Blueprints for the RDK X5 and RDK S100 display-module lesson.

Open an HTML file directly in a modern browser. The HTML files are self-contained and do not require network access.

## Verification scope

- X5 HDMI: connector, mode, image quality, repeat-run workflow, and cleanup are demonstrated.
- X5 DSI: a concise independent chain records the 4.3-inch display hardware, powered-off ribbon connection, and visible desktop output.
- S100 HDMI: the corresponding S100 workflow and measured result are kept separate from X5 claims.
- DSI evidence proves visible physical output only. It does not claim touch input, color calibration, or long-duration stability.

Board capabilities and interface details should be checked against the current official RDK documentation.
