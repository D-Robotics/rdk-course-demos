# RDK S100 40-pin GPIO / PWM courseware

This directory keeps the existing RDK X5 lesson unchanged and adds a minimal RDK S100 variant used for the course video.

- [中文课件](./lesson-11-s100-zh.html)
- [English courseware](./lesson-11-s100.html)

The S100 demonstration uses one LED with a 330-ohm series resistor. GPIO output is verified on physical Pin 37, and hardware PWM is verified on physical Pin 33 at 48 kHz. Both HTML files are self-contained and can be opened directly in a browser.
